# sunskritijain.com

Personal site for Sunskriti Jain. Plain HTML/CSS/JS, hosted on GitHub Pages.

- `site.html` — the page content (edit this one)
- `index.html` — generated; run `./build.sh` after editing `site.html`
- `photos/`, `files/` — images, pitch decks, and models
- `update_prices.py` — refreshes the pitch scorecard prices; runs weekdays via `.github/workflows/prices.yml`
